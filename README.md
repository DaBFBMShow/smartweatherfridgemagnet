## This is the Smart Weather Fridge Magnet. ##

The idea is simple. Basic parts, no soldering, custom software.

Made with an ESP-32, 1.69 inch LCD screen, and a 3.7v Battery.

# Details #

This is my first hardware project that I ever made :D

Made for Forge by Hack Club.

This project is currently in progress, and I am learning as I am making this! The plan is to make a smart magnet that can display the local weather wherever it is. It will have to be connected to wifi so it can receive up-to-date information about weather. It will stay updated by the hour. I am planning it to be showing the conditions, temperature, current time, and possibly UV or other weather information.

It is also planned for the magnet to have a 3d printed shell, printed either locally from my library, or online. The hardware is three items connected by solder-less wires, to make it easy and accessible. (And also, I don't own a soldering iron lol.) I will develop the software fully by myself, utilizing a free weather API if possible.
